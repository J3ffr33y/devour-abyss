# 设计方向评估（2026-10-28）

完整版：https://claude.ai/artifact/DJWmL5jf7s4foxhHdPDi7T

**结论**：方向值得做，但 v0.2 还是世界观设定，不是游戏设计。先冻结世界观扩写，用原型验证核心手感。

**亮点**
1. 器官 = 新动词 + 代价（16.2 节），和纯数值成长拉开差距。
2. 传奇海怪分阶段登场（第 15 章），制造恐惧的成本低。
3. 「我在吞噬海洋 → 我被海洋喂养」的反转和玩法绑定。
4. Boss 可以不杀。

**风险**
1. 游戏结构没定：roguelite（SYS-04）和银河城（SYS-03）互相矛盾。
2. 「从几毫米到巨兽」的尺度和镜头问题没有设计。
3. 器官在身上可见的模块化美术成本高。
4. 文档约 70% 是世界观和流程，容易用写设定代替做游戏。
5. 神秘盒子式叙事，建议私下先定真相。

**下一步**：定结构、视角、平台 → 2–4 周手感原型 → 尺度与器官原型 → 遗忘之海 + 白骨巨鲨垂直切片 → Steam 商店页。
