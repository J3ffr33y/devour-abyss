# 决策记录

> 拆分自《世界观与游戏设计圣经 v0.2》（原件见 `docs/source/design-bible-v0.2.docx`）。修改设定时直接改本文件，并在 `08-决策记录.md` 记一笔。

## 19 v0.2 决策记录与下一轮研究议题

- **决策ID**：决定 | 状态

- **DEC-020**：PC与手机采用统一工程，独立安装、独立存档 | 确立

- **DEC-021**：单机离线完整可玩，联机合作非首版必需 | 确立

- **DEC-022**：保留未来共同发育、合作Boss、共享巢穴的架构空间 | 方向确立；实现待评估

- **DEC-023**：所有生物科学真实性与架空边界必须标识 | 确立

- **DEC-024**：传说级海怪采用长期伏笔、生态预警、尺度揭示、后续战斗的分阶段登场 | 确立

- **DEC-025**：世界观不得堆砌不可解释的神秘名词，剧情必须有因果和角色动机 | 确立

- **DEC-026**：原初之母、循环次数与第零次灭绝真相暂不锁定 | 待研究

下一轮专题：①主角的生物学基本形态与器官兼容机制；②七大海域的真实生物群及食物网；③七大Boss的视觉预兆与分阶段剧情；④原初序列如何存储与重构生命信息的世界内约束；⑤可重复游玩的核心循环与移动端触控手感。

## 2026-10-28 与 Claude 讨论后的新决定

| 决策ID | 决定 | 状态 |
| --- | --- | --- |
| DEC-030 | 首发平台改为 Steam（PC），买断制；手机版在 PC 版验证好玩后再移植 | 确立 |
| DEC-031 | 一人开发，可用多个 AI agent 协助；目标是 2028 年 10 月前形成被动收入 | 确立 |
| DEC-032 | 首个发售版本控制在 2–3 小时、两到三个海域，12–15 个月内上线 | 提案 |
| DEC-033 | 先做手感原型（`prototype/feel/`），验证游动、吞噬、换器官本身好不好玩，再扩写世界观 | 确立 |
| DEC-034 | 推荐结构：银河城为主，巢穴存档，死亡只丢未带回的样本 | 提案 |
| DEC-035 | 推荐视角：2D 横向；推荐正式引擎：Godot 4 | 提案 |
| DEC-036 | 掠食者追击超过一定时间没咬到玩家就撤退，之后一段时间不主动攻击（原型默认 4 秒 / 5 秒，可调） | 确立 |
| DEC-037 | 玩法保持 2D；画面可考虑 2.5D（3D 渲染、平面操作），进入 Godot 阶段时做画面测试再定；不做完整 3D | 提案 |
| DEC-038 | **改做 3D**：第三人称自由游动，替代 DEC-035、DEC-037 的 2D / 2.5D 方案 | 确立 |
| DEC-039 | 3D 版首发只做 PC（Steam），手机版远期再评估；首版范围按 `09-3D方案.md` 收紧 | 确立 |
| DEC-040 | 引擎：推荐 Godot 4，备选 Unity，见 `09-3D方案.md` 第 2 节 | 待确认 |

> DEC-035、DEC-037 已被 DEC-038 取代。
