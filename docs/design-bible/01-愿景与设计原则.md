# 愿景与设计原则

> 拆分自《世界观与游戏设计圣经 v0.2》（原件见 `docs/source/design-bible-v0.2.docx`）。修改设定时直接改本文件，并在 `08-决策记录.md` 记一笔。

## 01 项目愿景与设计原则

### 1.1 一句话定位

在一片保存着灭绝生命、神话海怪与人类失踪记录的异常深海中，玩家作为能够吞噬并重构生命能力的微小个体，一边捕食成长、一边追索“原初序列”与自身诞生的真相。

### 1.2 三层体验

表层（立即好玩）：移动、捕食、闪避、能力切换和遭遇强敌；不读故事也能成立。

中层（持续游玩）：不同海域的生态、隐藏路径、稀有器官、史前物种、区域Boss和能力门槛。

深层（自主考古）：沉船、记录、记忆碎片、相互矛盾的证词以及生命历史的异常。

### 1.3 设计支柱

吞噬即选择：不是加数值，猎物能改变身体结构与操作方式。

弱小与未知并存：前期捕食体验直观，深处则越来越超出认知。

神秘不等于故弄玄虚：玩家能发现可检验的线索，而不是只读模糊文字。

史前与神话统一解释：通过“重构生命”的设定容纳异时空形态，不宣称其真实存在。

高内容密度、低资源依赖：有限场景与模块组合产生变化；不用实时服务器。

控制制作规模：世界观可宏大，但第一个可玩版本范围必须小。

### 1.4 非目标

首版不做实时联机、无缝开放大世界、自由 3D 游动（采用 2.5D：3D 画面、平面玩法）、数百个独立骨骼动画、复杂实时生态模拟、强制长剧情或依赖抽卡的成长。游戏并不以故意制造失控的重复游玩为目标。
