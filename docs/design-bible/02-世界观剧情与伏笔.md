## 02 世界规则与核心谜团

### 2.1 已建立的基础

2187年，NEREID深海探索计划在太平洋异常海沟发现一套生命网络：它能保存、重组并表达来自不同纪元的生命信息。几乎所有异常生物都存在共同结构“Genesis Sequence（原初序列）”，标记为 ORIGIN:000。[核心]

玩家是几毫米长的透明幼体，初始只感知水流、温度和饥饿。吞噬后可以获得对方部分器官、能力和残留记忆，但容纳空间有限，进化必须做取舍。[核心]

### 2.2 四个解释层

- **科学可见层**：生物样本、重构器官、重复基因结构、异常生态。

- **文明记录层**：古代船队、1973潜航器、2187 NEREID；传说可能是目击的文化化表达。

- **深渊意识层**：“原初之母”连接多个海域，似乎正在筛选容器；可能也是囚徒。

- **终极未知层**：所谓“第零次灭绝”和“第九次循环”是否为真实历史、模拟、预言或记忆篡改，暂不定论。

### 2.3 应保留的核心问题

深海中的远古物种是幸存、再造还是记忆的物化？

同一生命为何会重新出现，并保有上一次与玩家交锋的痕迹？

神话先于怪物，还是怪物先于神话？

所谓ORIGIN:000指玩家、母体、控制系统还是更古老的原型？

玩家为何接收到互相矛盾的记忆，甚至疑似未来的影像？

第零次灭绝与循环次数是否可信？

### 2.4 世界规则约束

异常机制局限于深渊网络影响区域；超自然表现需对应可观察的游戏内规律。史前生命以重构个体出现；传说怪物为架空改编，不等同于真实历史或宗教事实。较深海域中反常的空间、光照与“天空”必须标记为异常现象，而非真实海洋结构。

## 03 时间线与主要剧情结构

- **远古 / 具体年代未知**：[谜团] 深渊遗迹提及“第零次灭绝”；时间与可信度未知。

- **古代多个时代**：失踪船队记载巨蛇、岛屿生物与异常海面；传说留下重复图样。

- **1973年**：一艘秘密潜航器失联；最后讯息：“我们测到的不是海底。它有心跳。”

- **2187年**：NEREID计划发现生命网络，标本归档出现ORIGIN:000。

- **2187年 / 事故后**：基地全部样本同步苏醒，监控留有“SUBJECT 000 — RELEASED”。

- **游戏现在**：微小个体破卵而出；骨骸心跳；“第十次循环，已开始。”

### 3.1 五幕结构

**第一幕 / 饥饿**

生存、获得眼睛与基础器官、发现沉船；玩家以为只是奇异生态。

**第二幕 / 不可能的生命**

跨纪元生物、光纹语言、重复出现的怪物；确认世界不是自然连续演化。

**第三幕 / 人类证词**

1973记录、NEREID基地、异常实验体；玩家发现自己或曾被记录。

**第四幕 / 被培养的猎物**

原初之母似乎有意识地安排捕食路径，吞噬成为收集生命序列的过程。

**第五幕 / 第零次灭绝**

反转：原初之母可能不是最高存在。记忆显示互斥历史和疑似未来。

### 3.2 结局框架 [提案]

归一：接受网络融合，获得集合力量却失去独立意识。

吞神：拒绝融合并挑战母体，可能成为新核心，也可能重演循环。

自由（隐藏）：主动舍弃核心能力，切断连接，以有限生命游向海面。

制作原则：结局解锁由探索与进化选择决定，不以随机卡池或难以察觉的一次性陷阱决定。

## 12 伏笔矩阵与扩展治理

- **伏笔**：初见位置 → 潜在后续解释

- **相同的闪光节律**：暮光猎场 → 深渊网络同步指令或记忆编码

- **巨兽身上的人工伤痕**：失落纪元 → 人类实验或更古老文明干预

- **同一生物再次出现**：无光之国 → 重构复制与共享记忆

- **天空位于地下**：失落纪元 → 生物性投影、空间异常或错误认知

- **七个蛇首互相矛盾的记忆**：沉没神域 → 多个历史版本并存

- **第九次失败与第十次开始**：黑烟王庭/开场 → 实验循环或生命历史重启

- **ORIGIN:000**：初期生物样本 → 玩家、母体、原型可能共用的标识

### 12.1 待决策清单

主角是否有独立意识？从何时开始拥有记忆？

原初之母是否真有善恶意图，还是仅执行保存程序？

玩家是否能够通过选择不同器官改变叙事证据的解读？

海洋异常的真相最终公开多少？哪些答案永久保留？

采用连续大地图还是分区关卡？死亡后保留哪些进度？

神话生物作为Boss、地图级存在还是稀有事件如何分配？

实际的游戏美术风格与年龄分级定位。

### 12.2 内容扩展规则

每一个新条目须有：唯一ID、版本、状态、首次出现、视觉轮廓、玩法交互、关联谜团、奖励/发现、生产规模、依赖关系和可撤销性说明。不得直接修改已确立设定而不在版本记录写明原因。
