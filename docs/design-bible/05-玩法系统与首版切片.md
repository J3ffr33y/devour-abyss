# 玩法系统与首版切片

> 拆分自《世界观与游戏设计圣经 v0.2》（原件见 `docs/source/design-bible-v0.2.docx`）。修改设定时直接改本文件，并在 `08-决策记录.md` 记一笔。

## 09 核心玩法系统档案

### SYS-01  吞噬与生态食物链

**玩法系统独立档案**

- **系统目标**：大小关系只做基础门槛；弱点、状态、地形和技能可以改变捕食结果。敌人明确告知危险等级。

- **玩家循环**：移动 → 观察 → 接近 → 捕食 → 获取资源。

- **第一版范围**：首版3种猎物、2种威胁、1个环境利用机制。

**后续扩展**

每个新增能力记录：输入、冷却、能耗、交互对象、克制对象、可读提示和动画成本。

**质量门槛**

玩家必须能说出失败原因；升级改变至少一种实际操作或可探索空间，而不仅是攻击力提高。

### SYS-02  器官与进化槽

**玩法系统独立档案**

- **系统目标**：吞噬可提取序列；安装器官受体积、能量或兼容槽位约束；每种取舍改变操作手感。

- **玩家循环**：获取样本 → 选择器官 → 试用 → 调整构型。

- **第一版范围**：首版六个能力：光、冲刺、甲壳、触手、电击、墨汁。

**后续扩展**

- **玩家循环**：发现障碍 → 寻找对应生态能力 → 返回探索。

**玩法系统独立档案**

- **玩家循环**：战斗和探索形成小循环；长期进化形成大循环。

## 16 吞噬进化：让差异化落实为可玩的系统

### 16.1 吞噬≠复制一个技能

一次吞噬应触发“组织提取—生理兼容—形态表达—适应代价”。例如乌贼类启发的喷墨能力要有储存/消耗、散布条件和视觉掩蔽边界；电感受或电击结构的虚构强化要受水环境、能量与冷却约束。可用解剖学上的器官功能启发机制，但不能把现实中的物种功能无限夸张后仍称为事实。

### 16.2 形态与行为联动

器官至少改变一个实际玩家动词（抓取、探测、冲撞、伪装、迁跃、发光诱饵），并影响一个代价（耗氧、噪声、体积、速度、易被发现）。同一器官同时关联环境通路、捕食关系与Boss解法，才能让“进化选择”成为真正策略。

### 16.3 可控的组合空间

首个可玩版本建议3种基础移动形态、6–8个可获得器官、有限槽位与2–3条明显不同的路线。禁止在原型阶段堆出上百种仅数值不同的物种；有质量的10种能力优于无意义的100种技能。器官描述使用统一的数据字段：器官ID、来源生物、触发条件、主动/被动效果、能耗、冷却、冲突、动画接口、科学标签F/E/X。

## 11 开场脚本、体验节奏与首版切片

### 11.1 开场：第十次循环

深海无光，透明的卵缓慢漂浮。远处传来像心跳一样的低频震动。

卵裂，玩家以无眼幼体开始移动。界面只写：“活下去。”

吞下发光浮游体后首次获得视觉能力；画面逐渐显影。

原以为是海岩的轮廓，其实是成排的巨大骨骼；它们正在缓慢活动。

画面短暂闪现：“第十次循环，已开始。”

### 11.2 预期体验里程碑

- **前30秒**：捕食、移动、获得第一个反馈。

- **前5分钟**：获得一次明显改变玩法的器官能力。

- **前20分钟**：发现第一个需要能力才能通过的区域与一条谜团线索。

- **前2小时（完整游戏愿景）**：形成不同构型、理解两处海域与各自生态。

- **更长线（愿景）**：解锁历史证据、探查神话生命与分歧结局。

### 11.3 MVP：首个垂直切片 [建议]

建议只开发遗忘之海的一小块场景、暮光猎场的一处边界、6种器官、8–12种普通生物、1个完整Boss、一次碎片记忆和一处能力门槛。让玩家完成“弱小→捕食→构型变化→发现异常→挑战→回收线索”的小循环。

### 11.4 约束与技术

2D俯视/横向混合视角先择一，不同时做两种移动方案。

核心离线运行，不要求账号与自建游戏服务器。

移动端优先竖屏或横屏之一，基于实际操作测试确定。

轻量粒子和模块化动画，避免大规模实时物理模拟。

针对眩晕、闪烁、强对比提供可调节选项。

考虑Godot等轻量引擎，但引擎属于后续技术决策。
