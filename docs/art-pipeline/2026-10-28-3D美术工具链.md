# 3D 美术制作工具链（一人 + AI agent 版）

> 2026-10-28 调研。工具和价格变化很快，正式采购前再核对一次官网条款。
> 前提：Steam 买断、12–15 个月上线、一人开发、引擎 Godot 4。

## 0. 先说结论

1. 2026-10-28 已决定做**完整 3D 游戏**。本文只讲美术制作链怎么搭，玩法和关卡设计见 `docs/design-bible/`。
2. **完整 3D 的额外成本主要不在美术，而在程序和关卡**：三维镜头、三维寻路和追击 AI、上下方向感（水下没有地面参照，玩家容易迷路）、立体关卡和地图。AI 生成模型帮不上这部分，要在排期里单独留时间。
3. **美术侧的核心策略：** AI 生成初模 + Blender 清理 + Godot 程序动画，加上低多边形、自发光和雾的风格，把每只生物的制作时间压到可控范围。
4. **深海题材对一人 3D 很友好：** 鱼、鳗、水母、触手大多可以用程序动画或着色器动画做，不需要传统的骨骼绑定和逐帧动画；深海黑暗、雾和发光能遮住模型细节，对模型精度要求低。

## 2. 各环节怎么做

### 2.1 概念图
- 每种生物先定"剪影 + 发光点位置 + 配色"，深海里玩家主要靠这三样认怪。
- AI 出图适合快速试方向，但**最后一版风格设定图建议自己改过**，否则整套美术容易像"AI 素材拼盘"，在 Steam 评论区会被挑。
- Scenario 这类工具能用自己的图训练风格模型，让后续出图风格一致。免费额度只能个人评估用，商用要付费档。

### 2.2 AI 生成 3D（文字/图片 → 模型）
- 推荐流程：**概念图 → Tripo/Meshy 图生 3D → Blender 清理 → 导出 glb**。
- 现状：生成的模型适合做**中远景生物、道具、岩石、遗骸**；主角和 Boss 这种要反复看、要变形换器官的，生成结果通常只能当雕刻底模，需要在 Blender 里重拓扑。
- 授权要点：
  - Meshy 免费档产出是 CC BY 4.0（要署名），Pro 及以上归你所有。
  - Tripo 免费档不可商用，付费档可商用。2026 年起支持四足等非人形自动绑定。
  - Hunyuan3D 开源但授权**排除欧盟、英国、韩国**，Steam 全球发行有风险，不建议用在成品里。
  - TRELLIS.2 是 MIT 授权，可放心商用，但要本地显卡跑。
- **一定要用付费档生成要上线的资产**，并保存每个资产的生成记录（工具、日期、套餐），方便以后应对授权或 Steam 审核问题。

### 2.3 Blender（核心）
- 不管用多少 AI，Blender 都绕不开：减面、修破面、UV、调中心点和朝向、绑骨、导出。
- 建议投入 2–3 周专门学：基础建模、修改器（Decimate / Remesh / Mirror）、UV 展开、骨骼、glTF 导出。
- 风格建议：**低多边形 + 自发光 + 雾**（类似《Abzû》《Subnautica》远景的处理），比追求写实省力得多，也更耐看。

### 2.4 贴图
- 低模风格可以大量用顶点色和渐变贴图，几乎不需要画贴图。
- 发光器官单独做一张自发光贴图（emission），在 Godot 里配合 Glow 后期，是深海画面的关键。
- Substance Painter 有 Steam 买断版，如果以后要做精细材质再买。

### 2.5 绑定与动画（深海生物的捷径）
- **鱼、鳗、蛇形：** 一条骨骼链，在 Godot 里用正弦波驱动每节骨骼（或直接用顶点着色器摆动，连骨骼都不要）。游速越快摆动越快，转弯时身体自然弯曲，看起来很活。
- **触手、水母：** 程序动画（逆向运动学 IK 或弹簧骨骼），Godot 4.3+ 有 SkeletonModifier3D 可以写这类效果。
- **吞噬、换器官：** 器官作为独立模型挂到骨骼挂点上（BoneAttachment3D），换器官就是换挂件，不需要重做动画。这和设计里"数据驱动器官槽位"一致。
- **Boss 大招：** 少数关键动作在 Blender 里手 K 关键帧。
- Mixamo / AccuRIG 只对人形有用，本作基本用不上，可忽略。

### 2.6 导入 Godot
- 统一用 glTF 2.0（.glb）。Blender 导出时：+Y 朝上、应用变换、比例 1 米 = 1 单位。
- 在 Godot 里给每类生物做一个"导入预设"，统一碰撞体、材质覆盖、LOD。
- 规定命名：`creature_<名称>_<部位>.glb`，器官挂点骨骼统一命名 `socket_<槽位>`。

## 3. 让 Claude 直接操作工具（MCP 集成）

| 集成 | 能做什么 | 状态 |
| --- | --- | --- |
| **Blender 官方 MCP**（Blender Lab，GPL，2026-04 发布，需 Blender 5.1+） | 让 Claude 读场景、跑 Python 脚本批量处理：批量减面、改名、导出 glb、检查朝向 | Claude 的 Blender 连接器就是基于它 |
| **MCP for Blender**（原 ahujasid/blender-mcp，社区，MIT） | 同上，另外能直接调 Poly Haven、Sketchfab、Rodin、Hunyuan3D、Tripo 生成模型放进场景 | 适合实验，生成功能部分要付费 |
| **Godot MCP**（社区项目，如 Coding-Solo/godot-mcp） | 让 Claude 启动编辑器、运行项目、读报错、改场景 | 社区维护，质量不一，先试用 |

注意：
- 这两类 MCP 都要装在**你自己的电脑**上（Blender 和 Godot 跑在你那里），不是在云端这个会话里。装好后可以用 Remote Control 让我在你电脑上操作。
- Blender MCP 会执行 AI 写的 Python，官方提示没有安全防护。建议只打开项目文件夹里的文件，并且先提交 git 再让 AI 批量改。社区版可以设 `BLENDER_MCP_SAFE_MODE=1`。
- 最值得用 AI 的地方是**重复性的批处理**（导出、命名、减面、检查），而不是让它"设计一只怪"。

## 4. Steam AI 内容披露与授权

- Steam 2026 年 1 月更新了规则：**只用于提高开发效率的 AI 工具不用披露**（比如用 AI 写代码、用 AI 批处理模型）。
- **玩家能看到的内容由 AI 生成，就要在商店页披露**：美术、音效、文本、翻译、商店页图、宣传素材都算。
- 游戏运行中实时生成内容（如 AI 对话）要额外说明并做防护，本作不涉及。
- 做法：保留一份 `assets/ASSET_SOURCES.md`，每个资产记录来源（自制 / AI 生成后修改 / 第三方 CC0）。发售时据此写披露文字。
- 观感风险：部分玩家对"AI 美术"反感。AI 生成后经过明显的手工修改和统一风格处理，比直接用生成结果安全得多。

## 5. 3D 范围风险（如实说）

- 一人做 3D，最常见的失败是**美术量失控**：每种生物要模型、贴图、动画、换器官挂点、LOD，乘以三个海域、几十种生物。
- 控制办法：
  - 首版生物控制在 **15–20 种 + 2–3 个 Boss**，多用"同一模型换颜色和器官"做变种。
  - 风格选低多边形 + 发光 + 雾，不做写实。
  - 环境多用模块化岩石、珊瑚、遗骸拼装，一套素材复用整个海域。
  - 先做 1 个海域的垂直切片（完整美术品质），量出每种生物实际花多少小时，再定剩下的量。
- 完整 3D 的整体工期估计比 2.5D 多 30–50%（主要在镜头、AI、关卡），12–15 个月的目标会很紧。这是估计，没有实测依据，垂直切片后可以校准。保底办法：首版海域和生物数量宁少勿多，先保证一个海域做到能发 Steam 演示（Next Fest）的品质。

## 6. 建议的下一步

1. 装 Blender 5.x，花 2–3 周学基础（可以让 Claude 出一份按天的学习清单）。
2. 用 Tripo 或 Meshy 付费月卡生成 3 只测试生物（主角、小鱼、掠食者），走一遍"生成 → Blender 清理 → glb → Godot 程序游动"。
3. 量出每只花了多少小时，写回本文件。
4. 按实测工时定首版生物数量和海域数量。
