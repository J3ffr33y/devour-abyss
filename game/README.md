# Godot 工程（正式版）

2.5D 版本的起点：把 `prototype/feel/` 的手感规则搬进 Godot 的 3D 场景，玩法仍在 z = 0 的平面上。

## 怎么打开

1. 下载 [Godot 4.3 或更新的 4.x](https://godotengine.org/download)（标准版即可，不需要 .NET 版）。
2. 打开 Godot，点「导入」，选本文件夹里的 `project.godot`。
3. 按 F5 运行。

## 操作

- WASD / 方向键 / 手柄左摇杆：游动；按住鼠标左键也可以朝指针游
- 空格 / Shift / 手柄 A：冲刺（先吞下银色箭鱼）
- F / 手柄 Y：发光（先吞下发光水母）

## 已经有的

- 游动手感、吞噬（吸入、合嘴挤压、鼓包、顿帧、震屏、合成音效、连吞）、成长和镜头拉远
- 浮游生物、小鱼群、虾、发光水母、银色箭鱼、骨甲掠食者
- 掠食者平时在背景层游动，发现你后停顿、眼睛变红、浮到你的平面追击；4 秒没咬到就沉回背景层，5 秒内不再攻击
- 深度越深越暗，雾越浓；发光器官照亮周围
- 背景层：远处岩石和悬崖、巨型肋骨、装饰鱼群、每隔一段时间从深处游过的巨兽

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `scripts/feel.gd` | 手感参数，和 2D 原型一一对应（1 单位 = 2D 原型的 20 像素） |
| `scripts/player.gd` | 玩家：移动、吞噬判定、器官、外观 |
| `scripts/creature.gd` | 所有生物：种类数据、AI、掠食者的分层追击 |
| `scripts/main.gd` | 场景搭建、规则（吞噬、受伤、死亡）、镜头、HUD、音效 |

目前场景全部由代码生成，模型都是基础几何体占位，等美术流程跑通后替换成 glb 模型。

## 自动测试

设置环境变量 `ABYSS_TEST=<截图路径>` 运行时，会自动驾驶 12 秒、保存截图、打印数据后退出。
