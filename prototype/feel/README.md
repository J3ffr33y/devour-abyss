# 手感原型 v0.1

只验证一件事：在深海里游动、吞噬、长大、换器官，本身好不好玩。没有剧情，美术都是占位。

## 怎么玩

- 直接用浏览器打开 `index.html`（桌面或手机都行）。
- WASD / 方向键游动，或按住鼠标左键朝指针游；手机用左半屏摇杆。
- 空格：冲刺（先吞下银色箭鱼）。F：发光（先吞下发光水母）。
- T：手感参数面板。调到满意后点「复制参数」，把那串文字发给 Claude 写进默认值。

## 里面有什么

- 生物：浮游生物、小鱼群、虾、发光水母（给发光器官）、银色箭鱼（给冲刺器官，会累）、骨甲掠食者、深处的巨型掠食者。
- 掠食者发现你时会先停顿并在头顶出现「!」，然后追你。你长得比它大之后它会逃。
- 代价：发光耗能量、让掠食者更远就发现你；冲刺有声响，会惊动附近生物。
- 死亡后在起点重生，体型缩小 40%，器官保留。

## 试玩时请留意

1. 游动的惯性和转身手感对不对？
2. 吞东西爽不爽（顿帧、震屏、张嘴）？
3. 被掠食者追的时候紧张吗？「!」预警够不够清楚？
4. 拿到器官后，玩法有没有明显变化？
